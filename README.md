# Image preference study

A small two-alternative forced choice study, hosted as a static page. A
participant is shown two rows of generated images of the same class, one above
the other, and picks the row they prefer. Every pair of models is compared over
every class.

Open `index.html` to try it. There is no build step and no framework — the page
loads `manifest.js` (the trial design) and `study.js` (trial construction and
CSV shaping), and the images in `rows/`.

- **Deploying it:** see [DEPLOY.md](DEPLOY.md)
- **Collector:** [apps_script.gs](apps_script.gs) — a Google Apps Script web app
  that appends each response to a Google Sheet
- **Checking the logic:** `node selftest.mjs`

This folder is generated by `make_web.py` in the parent project, which converts
the source rows to WebP and writes `manifest.js`.
